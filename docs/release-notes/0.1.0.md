The first release of Kannu for Windows: a small notch at the top of your screen that shows what your AI
coding agents are doing, the Windows companion to Kannu for macOS.

**Install:** download `Kannu-win-Setup.exe` below and run it. This release is not code-signed, so
Windows SmartScreen warns the first time: click **More info**, then **Run anyway**. Kannu installs for
your user only and updates itself from here. Kannu asks you to accept its Terms of Use the first time
it starts. Beta testers: see the beta guide, docs/BETA.md in the repository.

## What's in it

- **The notch.** Hidden until something happens: when an agent starts, needs you (yellow) or finishes
  (red), it slides down from the top centre of the screen for a few seconds, then hides again. Click
  the Kannu eye in the taskbar to open it any time and see every session, with the agent's icon, the
  chat's name, how long it has run, its tool calls and, for Claude Code, its tokens. It never takes
  focus from your editor. Prefer it always visible, or as a floating pill? Both are in Settings.
- **Settings** in the Windows 11 style: the notch's shape and visibility, and a one-click hook
  install for each agent.
- **The tray eye.** Tinted with the most urgent light, with the session summary on hover.
- **Agent hooks** for Claude Code, Cursor, VS Code Copilot and Copilot CLI, Codex CLI, Antigravity,
  Gemini CLI, Qwen Code and opencode: install one from Settings › Agents and its new sessions appear on
  the notch. Your own hooks and settings are kept; the previous file is saved as `.kannu-backup`.
- **Without hooks:** Claude Code sessions (from their session records and transcripts), Cursor's
  agents, Warp's agent mode and Claude Desktop's agent mode still show up.
- **Click an agent to jump to it.** Click a session on the open notch and its window comes forward:
  the editor, Windows Terminal or Claude Desktop it runs in.
- **Notifications.** Settings › Notifications: Windows notifications when an agent needs you or
  finishes, phone notifications through ntfy, Pushover or your own webhook, and a "still waiting on
  you" reminder. All off by default. Only fixed texts are sent, never your chats.
- **Your traffic light.** Settings › Notch › Traffic light: Classic (three lights) or Minimal (one),
  your own colours for working, needs-you and finished (two states can never share a colour), and a
  gentle breathing while an agent works.
- **Notch skins.** Put a picture of your own behind the notch, with a slider to darken it so the lights
  stay readable.
- **Keep the PC awake.** Settings › Agents, or the sun button on the open notch: stop Windows sleeping
  while agents work (smart) or until you turn it off (manual). Both off by default.
- **Problem reports.** If Kannu crashes or freezes, it offers a report the next time it starts, with
  personal paths removed. Settings › About › Logs opens or exports the logs. Kannu starts at sign-in
  (turn it off in Settings › General).
- **Usage limits.** A Usage tab on the open notch shows Claude Code's 5-hour and weekly limits, when
  they reset and, at your current pace, whether you will run out first. Turn it on in Settings ›
  Agents › Usage limits; your own Claude statusline keeps working. Nothing is fetched from the
  internet. A notification comes when a limit reaches 95 %, if notifications are on.
- **Agent Security.** Kannu's hook now watches for hidden text in what agents read, secrets in your
  prompts and tool calls, agents reading or changing sensitive files (keys, saved credentials,
  browser data, startup items, agent settings), sessions running with permission checks off, and
  new MCP servers. A shield appears on the notch; details, acknowledge and snooze are in Settings ›
  Security. An agent policy file can block commands or tools in Claude Code and Cursor. Everything
  stays on this PC, and secrets are never stored. See docs/SECURITY.md.
- **Agents in WSL.** Settings › Agents › Agents in WSL installs Kannu's hook into Claude Code, Codex,
  Gemini CLI, Qwen Code and opencode inside your WSL distros; their sessions show on the same notch.
  Remove it there before uninstalling Kannu.
- **Codex without the hook.** Codex CLI sessions show on the notch even before you install its hook.
- **Small things.** Click anywhere outside the open notch to close it; put the notch on a display you
  choose; hide it from screenshots and screen sharing; Restart and Quit in Settings › About; a
  stopped-on-quota Claude card says when it resumes; Antigravity's sessions on the Usage tab.
- **ADR.** If you install Uber's ADR (Settings › Security shows the command), Kannu runs its Discovery
  scan daily and on MCP changes, and can analyse a finished chat on request. On Windows, ADR itself
  can't read files yet, so its scan is partial: it sees running programs, connections and installed
  apps.
- **Brightness and screen capture on the notch.** Settings › Notch › On the notch: a brightness bar
  when brightness changes, fine steps with Ctrl+Alt+F1 / F2, and a red dot while an app captures your
  screen (best effort). All off by default.
- **The usage forecast remembers** its readings across restarts.
- **Find any setting.** Type in the search box at the top of Settings; Kannu opens the page and
  highlights the row.
- **More than one monitor.** Settings › Notch › Placement: the main display, or wherever your pointer
  is. The notch also stays out of full-screen apps, games and presentations.
- **Ctrl+Alt+K** opens and closes the notch from any app (Settings › General, off by default).
- **A short welcome** the first time Kannu starts: what the lights mean and how to connect your agents.
- **Automatic updates** from GitHub Releases, applied the next time Kannu starts.

Kannu for Windows reads and writes the same status files as Kannu for macOS
(`%USERPROFILE%\.kannu\agent-status`).

Requires Windows 10 or 11 (x64). Everything Kannu needs, .NET included, is in the installer.
