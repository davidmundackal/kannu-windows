The first release of Kannu for Windows: a small notch at the top of your screen that shows what your AI
coding agents are doing, the Windows companion to Kannu for macOS.

**Install:** download `Kannu-win-Setup.exe` below and run it. This release is not code-signed, so
Windows SmartScreen warns the first time: click **More info**, then **Run anyway**. Kannu installs for
your user only and updates itself from here. Kannu asks you to accept its Terms of Use the first time
it starts. Beta testers: see the beta guide, docs/BETA.md in the repository.

## What's in it

- **The notch.** Hidden until something happens: when an agent starts, needs you (yellow) or finishes
  (red), it slides down from the top centre of the screen for a few seconds, then hides again. Click
  the Kannu eye in the taskbar to open it any time and see every session, with the agent's icon, the
  chat's name, how long it has run, its tool calls and, for Claude Code, its tokens. It never takes
  focus from your editor. Prefer it always visible, or as a floating pill? Both are in Settings.
- **Settings** in the Windows 11 style: the notch's shape and visibility, and a one-click hook
  install for each agent.
- **The tray eye.** Tinted with the most urgent light, with the session summary on hover.
- **Agent hooks** for Claude Code, Cursor, VS Code Copilot and Copilot CLI, Codex CLI, Antigravity,
  Gemini CLI, Qwen Code and opencode: install one from Settings › Agents and its new sessions appear on
  the notch. Your own hooks and settings are kept; the previous file is saved as `.kannu-backup`.
- **Without hooks:** Claude Code sessions (from their session records and transcripts), Cursor's
  agents, Warp's agent mode and Claude Desktop's agent mode still show up.
- **Automatic updates** from GitHub Releases, applied the next time Kannu starts.

Kannu for Windows reads and writes the same status files as Kannu for macOS
(`%USERPROFILE%\.kannu\agent-status`).

Requires Windows 10 or 11 (x64). The installer adds the .NET 8 Desktop Runtime if it is missing.
